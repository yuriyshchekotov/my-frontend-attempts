Что такое CSS?

CSS (Cascading Style Sheets) - это язык стилей, который делает HTML красивым.

Без CSS все сайты выглядели бы как скучные документы.

Что можно делать с CSS?

  • Менять цвета и шрифты
  • Создавать макеты страниц
  • Добавлять анимации
  • Делать сайты адаптивными
